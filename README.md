# 🧠 AI Fitness Recommendation System

## 📌 What This Project Does
This project takes user inputs like age, weight, height, and diet preference and provides:

- Daily calorie requirement  
- Protein intake recommendation  
- Basic health analysis  

---

## ⚙️ How It Works

This system follows a simple pipeline:

User Input → Calculation → Decision Logic → Output

- BMI is calculated using height and weight  
- BMR is calculated using standard formulas  
- Conditions are applied to generate recommendations
